# 🚗 India Road Accident Data Analysis & Safety Insights

An interactive data analysis project focused on understanding road accidents in India and identifying important safety patterns and insights using data analytics and visualization.

---

## 📌 Project Overview

Road accidents are a major public safety concern in India. This project analyzes road accident data to understand accident patterns, fatalities, road conditions, vehicle involvement, and other factors associated with road accidents.

The project combines **Python, MySQL, and Power BI** to clean, analyze, visualize, and present meaningful insights from the dataset.

---

## 🎯 Problem Statement

Road accident data contains valuable information about accident frequency, fatalities, vehicles, road conditions, and other contributing factors.

However, raw data alone does not easily reveal important patterns.

This project aims to:

- Analyze road accident patterns in India
- Identify major factors associated with accidents and fatalities
- Study accident trends across different years
- Analyze vehicle involvement
- Understand the impact of road and environmental conditions
- Create meaningful visualizations and dashboards
- Provide data-driven safety insights

---

## 🎯 Objectives

1. Clean and preprocess the road accident dataset.
2. Perform exploratory data analysis using Python.
3. Store and query structured data using MySQL.
4. Create interactive dashboards using Power BI.
5. Identify important accident and fatality patterns.
6. Present insights in an easy-to-understand format.

## 📊 Dataset

The project uses an India road accident dataset covering the period:

**2018–2024**

The dataset contains multiple attributes related to:

- Accidents
- Fatalities
- Vehicles
- Road conditions
- Weather conditions
- Location
- Time
- Road type
- Safety-related factors

The dataset contains approximately **25 attributes** used for analysis.

---

## 🔎 Key Analysis Areas

The project analyzes several important areas:

### 📅 Year-wise Analysis
Study how accident numbers and fatalities vary across different years.

### 🚘 Vehicle Analysis
Analyze the involvement of different vehicle categories in road accidents.

### 🛣️ Road Analysis
Study accident patterns across different road and highway conditions.

### 🌦️ Environmental Factors
Analyze the relationship between accidents and environmental conditions such as weather.

### 🪖 Helmet Safety Analysis
Study the relationship between two-wheeler non-helmet usage and fatality outcomes.

### 📍 Location-based Analysis
Identify geographical patterns in accident data.

---

## 📈 Key Metric

One of the important metrics calculated during the analysis was:

**2-Wheeler Non-Helmet Mortality Odds Ratio: 42.74**

This metric was used to examine the association between non-helmet usage among two-wheeler occupants and mortality outcomes in the analyzed dataset.

> Note: This is an association calculated from the dataset and should not automatically be interpreted as proof of causation.
